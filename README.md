# Neuro-Ninja Kids

Aplicación estática para retos diarios de atención, memoria y coordinación. Abre `index.html` localmente o publícala con GitHub Pages.

## Publicar

El workflow de GitHub Actions está en `.github/workflows/deploy.yml`. Al subir `main`, despliega el sitio con GitHub Pages. En el repositorio, selecciona **Settings → Pages → Source: GitHub Actions**.

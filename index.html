1. Secret hand code

The child follows the 6 rows and performs both actions at the same time. Repeat today’s challenge if they need more practice.

  • Red: fist
  • Blue: flat palm
  • Yellow: karate chop

2. Flash memory grid

Show a 3 × 3 grid with 5 colored tiles for 5 seconds. Cover it and ask the child to recreate the pattern with bottle caps or blocks. Then show the answer in the app.

3. Schulte number hunt

The child searches for and taps the numbers from 1 to 16 in order. In Ninja mode, use the left hand for odd numbers and the right hand for even numbers. Use today’s board; the child may repeat it if needed.

4. Spatial dictation

Give the child a sheet with a grid. Start at the red dot and dictate one instruction at a time without revealing the shape. Each move equals one square.
